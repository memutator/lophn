# lophn 0.4.0

Tabs can now float over the workspace, shrink to a bar at the top, or leave the window as their own window. Web pages open inside lophn as browser tabs, and web links from the terminal open there too.

## New
- Browser tab: choose Browser from the new-tab menu to open a web page inside lophn. It has back, forward, reload, an address bar, bookmarks, and Open in browser. Sign-ins are kept across browser tabs and projects.
- Sign-in popups open in a floating panel. Dock it to turn the page into a normal tab.
- Bookmarks for browser tabs: add one with the star button or Ctrl/Cmd+D, and manage them under Settings > Browser.
- Settings > Browser > Clear browsing data removes cookies, storage, and cache.
- DevTools for a browser tab opens beside the page. You can move it to a floating panel or a separate window.
- Browser tabs and bookmarks show the page's icon.
- Float, Minimize, and Dock any tab. A minimized tab stays in the top bar; click it to bring it back.
- Detach a tab into its own window from the tab menu. The terminal keeps running in the new window, and the window can go to another screen. Dock returns the tab to the project window. When you close a project, its detached windows close and reopen in the same place the next time.
- Web addresses shown in the terminal can be opened with Ctrl-click (Cmd-click on macOS), and a command that opens a web address, such as `gh auth login --web`, opens it in a browser tab.

## Changed
- Links from the terminal open in a browser tab by default. Settings > Browser > Links can send web links or local links to the system browser instead.
- Tab shortcuts (next, previous, close, reopen, move left, move right) work even when the focus is in an app panel or a browser page.
- Your saved workspace layout from earlier versions is not kept. lophn starts with a new layout after you update.

## Fixed
- Reopening a minimized app panel no longer shows the state it had when it was minimized.
- Docking or floating a sign-in popup right after it opens no longer shows an error page.
- The drag handle between panes is no longer partly hidden under a browser page.
- A new agent chat started from a detached window no longer brings an existing chat to the front.
- DevTools no longer disappears when moved from a detached window to a floating panel.
- Sign-in popups in a detached window open at the requested size.
- A detached terminal reconnects when you go back to its project, as long as lophn has not been restarted.
- mailto and tel links in a browser page open in your mail or phone app.
- Http and https links in an artifact tab open in a browser tab.
