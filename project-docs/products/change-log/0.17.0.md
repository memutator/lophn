# 0.17.0

## browser 탭의 Google 로그인

```yaml
modules: [packages/shell/main]
checked: []
```

- 전: browser 탭에서 Google 계정 로그인이 막혔다. header의 `sec-ch-ua`에는 지어 넣은 `Google Chrome` brand와 낡은 GREASE(`Not=A?Brand`)가 실리고, page JS의 `navigator.userAgentData`는 Electron 값(`Chromium`과 `Not?A_Brand` 둘)이라 서로 어긋났다.
- 후: header의 `sec-ch-ua`·`sec-ch-ua-full-version-list`와 page JS의 `navigator.userAgentData`가 모두 그 Chromium 판의 Google Chrome 값이다. page JS 값은 browser contents마다 CDP `Emulation.setUserAgentOverride`로 넣는다. Chromium이 싣지 않은 client hint header는 더하지 않는다.

왜: 사람이 browser 탭에서 Google 로그인이 안 된다고 했다(사람 2026-11-03).

결정:
- page JS 값은 CDP debugger로 바꾼다. 표준 Electron에는 다른 길이 없다. (agent)
- GREASE brand와 순서는 Chromium의 `GenerateBrandVersionList`를 따라 계산한다. 고정 문자열은 판이 바뀌면 진짜 Chrome과 어긋난다. (agent)
