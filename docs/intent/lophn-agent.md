# lophn-agent

## 왜

앱을 만든 뒤 무엇을 고칠지, 누구에게 맡길지까지 내가 챙기면 유지 비용은 줄지 않는다. lophn agent는 판단과 설명을 맡고, 내 결정은 내게 남긴다.

## 무엇을 약속하나

- **[I1]** lophn agent는 코드를 짜지 않고, 맡은 책임과 내가 허락한 자료·도구 안에서만 일한다.
- **[I2]** 반복하는 일은 내가 승인한 주기로만 돌고, 멈추면 저절로 다시 시작하지 않는다.
- **[I3]** 내 요청과 세션은 잃지 않고, 다른 역할에 넘겨도 원래 목적이 이어진다.
- **[I4]** 되돌릴 수 없는 일은 반드시 내 승인을 받고, 내 답이 없으면 승인으로 보지 않는다.
- **[I5]** agent가 무엇을 왜 했는지 되짚을 수 있고, 되돌릴 수 있는 일은 되돌린다.
- **[I6]** skill과 외부 MCP를 붙여도 허락한 범위를 넘지 않는다.
- **[I7]** 질문은 필요한 만큼만, 선택지와 추천을 함께 묻는다.
- **[I8]** 판단 품질은 eval로 확인한다.
- **[I9]** agent는 답할 때 표·차트·앱 카드를 세션 안에 바로 보여 준다.
- **[I10]** 세션에 그린 것은 원하면 문서로 남긴다.
- **[I11]** agent는 앱이 허락한 자리에만 힌트나 주석을 단다.

## 하지 않는 것

- 코딩 도구나 채팅 중심 비서를 만들지 않는다.
- 자료 변화만으로 판단을 시작하거나, 다른 역할에 맡기며 권한과 승인을 옮기지 않는다.
- agent의 완료 주장만으로 고쳤다고 인정하지 않는다.
