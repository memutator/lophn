# lophn 0.21.0

This release fixes blank screens in tabs, app sidebar panels, and tray popups, and moves the header row of app screens into lophn's own frames.

## New
- Apps can show a standard icon on a header button (refresh, add, open, edit, delete, copy, run, stop, download).

## Changed
- App sidebar panels and tray items appear as soon as an app declares them. Before, you had to switch them on in Settings › Quick launch. They are now on by default; switch off the ones you do not want there. The tray shows nothing when it has no items.
- The header row of an app screen (path, tab name, status, buttons, ⋯ menu) is drawn by lophn in the tray popup, app sidebar panels, floating app panels, and session app cards. In the tray popup, the header shows only icon buttons; the status text, path, tab name, and ⋯ menu are not shown there.
- lophn checks the installed SDK version on each start, so the SDK update notice also appears when only the SDK changed and lophn itself stayed the same.

## Fixed
- A tab whose content failed to draw blanked the whole lophn window (for example, the Project settings tab showing "Input needs a Field label"). Now only that tab shows a short message with a Try again button, and the rest of the window keeps working.
- App sidebar panels and tray popups showed "Couldn't load …" instead of the app's screen. They open now.
- The app list for sidebar panels, the tray, and quick launch stayed stale until the window was reopened. It updates now when lophn becomes ready and when an app's new version becomes active.
- Session app cards with no version chosen failed to open. They open the app's current version now; if the app has no adopted version yet, the card shows an unavailable message.

## Action needed
- If your app draws its own header row, have its agent move the app to `@lophn/app-ui` 2.7.0 and remove the app's own header. Until then, the header shows twice in those places.
- Sidebar panels and tray items that now appear by default and that you do not want: switch them off in Settings › Quick launch. Ones you had already switched on stay on.
