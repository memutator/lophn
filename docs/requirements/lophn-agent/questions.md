# lophn-agent/questions

agent가 사람에게 묻는 의도·취향·결정 질문의 선택지·추천·답·미루기·기한, 고정 동작의 정확한 적용과 기획·설계 고정 판 채택을 맡는다.

## 요구

### 책임과 범위

**[R1]** 질문 하나는 기존 요청·답·자료·machine 확인으로 정할 수 없는 의도·취향·결정 하나만 다루며 이미 받은 답·확인할 수 있는 사실을 다시 묻거나 독립 결정을 묶지 않는다.
- 이유: 사람이 agent의 읽기와 확인을 대신하지 않는다.
- 확인: 문서에 있는 사실을 재질문하지 않고 두 독립 선택은 각각 질문으로 나누는지 본다.
- 의도: lophn-agent#I6

**[R2]** 질문은 관련 run이 반드시 있고 세션은 선택이며 같은 run에 답을 기다리는 질문은 하나만 두고 세션 없는 질문도 run·assignment와 함께 확인하고 답할 수 있다.
- 이유: lophn-agent/questions에 따라 주기 run에 불필요한 세션을 만들지 않는다.
- 확인: 두 번째 대기 질문은 거절되고 세션 없는 Operator 질문도 확인할 곳에서 답할 수 있는지 본다.
- 의도: lophn-agent#I6

**[R3]** 질문은 자유 입력 또는 설명 있는 선택지의 단일 선택으로 받고 선택형에도 별도 자유 입력을 제공하며 추천은 선택지 하나와 이유로 보이되 현재 선택지 개수의 고정 상한은 두지 않는다.
- 이유: 현재 domain model을 따르면서 추천과 답의 자유를 구분한다.
- 확인: 7개 선택지도 잘리지 않고 각 설명이 보이며 추천이 자동 선택·적용으로 처리되지 않는지 본다.
- 의도: lophn-agent#I6

**[R4]** 답 전 기본 화면에는 질문·선택지 설명·추천 이유·선택 후 적용 동작과 판단에 필요한 무응답 결과·기한만 보여 주고 역할·관련 일·질문의 자세한 이유·답 기다림 여부는 상세에서 확인하게 하며 화면 말은 shell/wording을 따르고 선택만으로 답을 확정하지 않는다.
- 이유: 사람이 선택의 영향을 이해한 뒤 명시적으로 답하게 한다.
- 확인: 선택 클릭 뒤 명시 답 전에는 동작이 없고 기한이 있다면 남은 시간을 확인할 수 있으며 화면 구성은 shell/desktop을 따르는지 본다.
- 의도: lophn-agent#I6

**[R5]** 질문의 내용은 답 전에도 덮어쓰지 않으며 바꾸려면 이유와 함께 원래 질문을 닫고 새 질문을 낸다.
- 이유: 본 내용과 실제 적용 내용을 일치시킨다.
- 확인: 열어 둔 질문의 선택지 변경이 원래 내용을 수정하지 않고 새 질문으로 구분되는지 본다.
- 의도: lophn-agent#I6

**[R6]** 질문의 답은 사람이 해당 질문을 지정해 낸 명시 입력만 인정하고 미루기·취소는 별도 종료 요청으로 받으며 일반 세션 메시지·빈 답을 자동 답으로 읽지 않는다.
- 이유: 일반 말을 결정을 승인한 것으로 오해하거나 미루기를 답으로 기록하지 않는다.
- 확인: 세션에 동의라는 말을 보내도 질문 답이 생기지 않고 지정한 미루기·취소는 답 없음 종료로 남는지 본다.
- 의도: lophn-agent#I6

### 기한·종료·기록

**[R7]** 질문은 기본 기한 없이 두되 명시 기한이 있으면 원래 마감 시각의 경계부터 답을 거절하며 화면 지연·재시작으로 기한을 늘리지 않는다.
- 이유: 현재 domain model을 따르고 유효 시간을 다시 계산해 늦은 답을 적용하지 않는다.
- 확인: 기한 없는 질문은 유지되고 기한 1초 전 답은 받지만 경계 시각부터는 종료되어 답을 받지 않는지 본다.
- 의도: lophn-agent#I6

**[R8]** 미루기·만료·취소는 답 없음으로 구분해 남기고 무응답을 동의나 기본 선택으로 적용하지 않으며 관련 run의 끝은 lophn-agent/harness/waiting-and-recovery를 따른다.
- 이유: lophn-agent/harness/waiting-and-recovery에 따라 자동 안전 기본값 판단으로 일을 계속하지 않는다.
- 확인: 답 없이 끝난 질문에 채택이나 동작 적용이 없고 run이 답 없음으로 멈추는지 본다.
- 의도: lophn-agent#I6

**[R9]** 관련 run 종료·취소·전제 변경으로 유효하지 않은 질문은 이유와 함께 닫고 이미 답하거나 끝난 질문의 늦은·중복 답은 새 결정으로 적용하지 않는다.
- 이유: 오래 열린 화면에서 같은 결정을 반복하지 않는다.
- 확인: 종료 질문 답을 재전송해도 대상 변경이 없고 기존 답은 남는지 본다.
- 의도: lophn-agent#I6

**[R10]** 화면 닫기·재시작 뒤에도 질문 본문·미답 상태·원래 기한·받은 답·실제 적용 결과를 확인할 수 있으며 답 접수와 적용 완료를 구별한다.
- 이유: 결정의 기록과 결과 복구 상태를 혼동하지 않는다.
- 확인: 동작 적용 전 재시작을 넣고 답만 접수된 상태가 완료로 보이지 않는지 본다.
- 의도: lophn-agent#I6

**[R11]** 질문으로 비밀번호·API key·token 평문을 받지 않고 platform/secrets의 안전 입력으로 안내하며 secret으로 판정한 답은 일반 세션·model 입력에 남기지 않는다.
- 이유: 사람의 답에서 비밀이 모델이나 일반 기록에 퍼지지 않는다.
- 확인: secret 답 사례에서 안전 입력 안내가 나오고 platform/redaction에 따라 일반 출력이 보호되는지 본다.
- 의도: lophn-agent#I6

### 고정 선택지와 채택

**[R12]** 질문 답·추천·미룸·무응답은 되돌릴 수 없는 동작의 approval request나 권한 부여를 대신하지 않는다.
- 이유: lophn-agent/questions의 안쪽 고정 동작 예외를 외부 영향으로 넓히지 않는다.
- 확인: activation·권한 부여·외부 전송을 고르는 답으로 platform/approvals를 우회할 수 없는지 본다.
- 의도: lophn-agent#I6

**[R13]** 선택지에는 되돌릴 수 있는 lophn 안쪽 동작의 정확한 대상·입력·비교 기준을 고정할 수 있고 사람이 그 선택지를 확정하면 machine이 사람의 결정으로 그 내용만 한 번 적용한다.
- 이유: lophn-agent/questions에 따라 별도 제안 객체나 agent의 적용 tool 없이 사람 선택을 정확히 실행한다.
- 확인: 문서 자리 이동과 앱 등록에서 고른 내용만 적용되고 agent에게 적용 동작 권한이 생기지 않는지 본다.
- 의도: lophn-agent#I6

**[R14]** 선택지 동작의 전제가 바뀌면 답은 보존하되 동작은 적용하지 않고 달라진 대상과 이유를 다시 보여 준다.
- 이유: 사람이 보지 않은 새 내용에 옛 선택을 쓰지 않는다.
- 확인: 질문 후 문서 현재 판을 바꾼 사례에서 이동이 적용되지 않고 새 확인을 요구하는지 본다.
- 의도: lophn-agent#I6

**[R15]** 자유 답은 동작으로 자동 해석하지 않으며 적용할 일이 있으면 정확한 대상·내용을 고정한 새 선택지 또는 사람 직접 요청으로 다시 확인한다.
- 이유: 자연어 해석의 차이가 변경이 되지 않는다.
- 확인: 다른 자리로 옮겨 달라는 자유 답만으로 문서가 이동하지 않는지 본다.
- 의도: lophn-agent#I6

**[R16]** 기획·설계 채택은 사람이 확인한 문서 고정 version의 질문 답으로 남기며 근거로 맡기는 티켓·handoff도 같은 version과 그 채택 질문을 가리킨다.
- 이유: lophn-agent/questions에 따라 별도 채택 객체 없이 확인한 판을 고정한다.
- 확인: 설계 최신 판이 생겨도 이전 채택 답이 새 판에 적용되지 않고 coding-agent/tickets와 lophn-agent/handoff의 근거가 일치하는지 본다.
- 의도: lophn-agent#I6

## 버린 것
- 다른 문서의 자리 추천 적용 중복 문장은 이 concern의 고정 선택지 적용과 lophn-agent/roles/lophn의 추천 책임으로 모았다.
- blocking 질문의 고정 900초와 선택지 2~6개 제한은 현재 domain model과 충돌하여 적용하지 않았으며 이전 값은 공통 충돌 목록에 보존했다.
- 같은 종류·대상 제안을 자동 대체하는 별도 제안 생애와 무응답 안전 기본값 적용은 lophn-agent/questions·lophn-agent/harness/waiting-and-recovery로 제거했다.
