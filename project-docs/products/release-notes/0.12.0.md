# lophn 0.12.0

This release tidies up the chat screen and makes queued messages and the working status easier to follow.

## Changed
- The working line in the conversation shows how long the agent has been working and the tool it is running now, for example "Working 18m · <tool>". It shows "Thinking" while the agent only reasons.
- The message box has one round button. It is a faded send button when the box is empty and the agent is idle, a filled send button when you have typed text, and a filled Stop square while the agent runs with an empty box. While the agent runs with text in the box, it shows send, which queues the message for the next turn. Esc still stops the agent.
- Effort and speed are chosen only from the model menu. Usage (context window, tokens, cost) sits at the right end of the line with the place and permissions.
- Cost reads like `$2.06`, without "About".
- The /status panel opens above the message box as an overlay, so the conversation stays visible. Its token line is now a ratio bar with a legend.
- Edit cards fit on one line: a chevron, the changed file's name with its line counts, and Open at the right end.
- The time next to agent replies, the blinking caret at the end of streaming text, and Retry on the last finished turn are gone. Fork on your own messages is gone too. Fork from here on agent replies and Retry on error lines stay.

## Fixed
- [Send now] and [x] on a queued message now update the line right away. Before, the line stayed, and clicking again said "That didn't work".
- Editing and reordering queued messages no longer fail with a "forbidden" error.
- Messages you send into a running turn now show as steering in the conversation.
- After a brief connection drop, the conversation catches up on what it missed instead of staying stale.
- The conversation no longer goes blank for a moment when a streaming reply is saved.
- Long turns of tool calls and reasoning no longer look stuck in the Messages view.
