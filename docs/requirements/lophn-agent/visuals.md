# lophn-agent/visuals

agent가 답의 일부로 세션에 남기는 선언형 표·차트·도표와 앱 카드, 크기 검사와 문서로 남기기를 맡는다; 그리는 틀은 shell/workspace, 재료는 apps/sdk와 documents/formats를 따른다.

## 요구

**[R1]** 시각 블록은 표, 막대·선·산점 차트, node와 edge로 된 도표, 앱 카드만 선언형 종류·데이터·설명으로 받아 SDK 컴포넌트로 그리고 agent가 보낸 HTML·JavaScript·CSS·임의 URL은 실행하지 않는다.
- 이유: 세션의 그림을 코드 실행 통로로 만들지 않는다.
- 확인: 지원 종류의 정상 명세는 보이고 script·알 수 없는 종류·URL 입력은 거절되는지 본다.
- 의도: lophn-agent#I9

**[R2]** 블록은 제목·텍스트 설명·읽은 문서 고정 version 또는 앱 command 결과의 출처를 함께 남겨 근거 없는 값과 없는 데이터를 실제 관측값으로 채우지 않는다.
- 이유: 그림에서도 근거와 추정을 구별한다.
- 확인: 빈 데이터는 빈 상태이고 수치·출처·누락을 글로 확인할 수 있는지 본다.
- 의도: lophn-agent#I9

**[R3]** 메시지 하나는 블록 최대 8개와 모든 명세 합계 UTF-8 256 KiB, 블록 하나는 표 1,000행·20열, 차트 8 series·전체 1,000점, 도표 100 node·200 edge 상한을 검사하여 초과 입력은 자르지 않고 더 작은 블록을 요청한다.
- 이유: 화면과 저장 크기를 제한하되 일부를 전체처럼 보여 주지 않는다.
- 확인: 각 상한과 바로 다음 값에서 정상 수용과 전체 거절이 구별되는지 본다.
- 의도: lophn-agent#I9

**[R4]** 앱 카드는 apps/blueprint에서 카드 크기를 지원한 화면만 참조하며 열린 카드·탭·문서 링크가 앱 command 실행 권한을 늘리지 않는다.
- 이유: 반응형 앱만 끼우고 보기와 실행 허락을 분리한다.
- 확인: 카드 미지원 화면은 거절되고 카드 클릭으로 agent의 범위가 확대되지 않는지 본다.
- 의도: lophn-agent#I9, lophn-agent#I1

**[R5]** 블록이 깨지거나 앱·화면·release를 더는 열 수 없어도 메시지 본문과 설명·원래 참조를 보존하여 이용 불가로 표시하고 다른 앱이나 최신 release로 몰래 대체하지 않는다.
- 이유: 세션 기록은 앱의 현재 수명과 독립적이다.
- 확인: 앱 archive와 renderer 오류 뒤 본문·설명·출처가 남는지 본다.
- 의도: lophn-agent#I9

**[R6]** 사람이 문서로 남기기를 요청하면 선택한 블록의 고정 명세·데이터·설명·출처와 그 순간의 그림을 실행 코드 없는 HTML 문서로 준비하여 해당 역할의 문서 저장 범위와 documents/formats·documents/versions 계약으로 저장한다.
- 이유: 그림을 다시 확인할 수 있는 독립 문서로 만든다.
- 확인: 세션을 닫아도 저장한 문서를 읽을 수 있고 기존 문서 충돌과 Operator 쓰기 범위는 우회되지 않는지 본다.
- 의도: lophn-agent#I10

**[R7]** 앱 카드의 문서 저장은 앱이 허락한 redaction된 snapshot과 고정 앱 참조를 남기고 snapshot을 얻지 못하면 이용 불가와 참조만 남기며 살아 있는 앱 화면·credential을 문서에 넣지 않는다.
- 이유: 오래 남는 문서는 live 앱과 secret을 복제하지 않는다.
- 확인: 앱 종료 후 저장 문서에 snapshot 또는 명시적인 부재가 보이고 외부 요청·credential이 없는지 본다.
- 의도: lophn-agent#I10
