# lophn 0.20.0

This release makes agent sessions in apps safer and easier to follow, adds a permanent History to Inbox, and moves SDK update handling to lophn.

## New
- Inbox has a History tab that keeps a permanent record of releases, apps that stopped, app data migrations, and lophn updates. You can filter it by app, project, kind, and date range, and search it.
- Inbox shows one notice when apps need or could use a newer SDK. Use Ask lophn on it to have lophn update those apps.
- The app detail Version tab shows the required, available, and current version of each SDK.
- Each agent has a handle, a fixed address that never changes, and a name you can change. An agent can be limited to one project or app.
- Browser tabs have a Keep alive option in their ⋯ menu.
- With the taskbar on, the quick launch buttons and the Settings gear sit on the taskbar. The tray popup has a Keep open pin.

## Changed
- Apps can no longer approve requests or rewind or fork agent sessions. Approvals are done in the chat tab only.
- An app's agent session keeps its title and reconnects when you return to the app, so the answer to a turn that was still running is not lost. Turns that finish in an app's session no longer send a Finished notification.
- Approvals and questions from an app's agent still notify you when the app is not on screen.
- An app's share request appears inside its consent card, so one approval covers both.
- Pages in apps and browser tabs unload when you switch projects, unless they ask to stay alive, for example while an agent is answering, playing sound, or downloading. Up to six pages per window are kept.
- Archived apps are hidden from lophn's agents. You can still restore them yourself on screen.
- Notifications from apps are temporary by default. An app can mark a notification as persistent so it stays in History.
- Agents waiting for your approval or an answer show as waiting in session lists.
- When lophn builds an app that needs an agent, it creates a dedicated agent for that app instead of using the general lophn agent.
- The Inbox badge in the sidebar also counts unread History entries.

## Fixed
- Tool calls with very large results, such as big images or large web fetches, no longer stay in a running state forever.
- Project settings no longer blanks the whole window when its terminal command list fails.
- The tray popup no longer floats away from its item when it opens.
- Apps built with the agent SDK no longer show type errors from the installed SDK copy.

## Action needed
- Apps that show an SDK update notice in Inbox need that update. Use Ask lophn on the notice, or update the app yourself.
- To use the new agent session features, update apps to version 1.3.0 of the agent SDK.
