# lophn 0.10.1

You can sign in to OAuth-based MCP servers, remove saved app secrets, and get a hint when an error happens.

## New
- Add an MCP server that uses OAuth 2.1 in Settings › Tools and skills, or in a project. Enter the issuer, client ID and scopes, then click Sign in. Cancel stops a sign-in that is still waiting. The client secret is optional.
- An agent's own MCP servers can use OAuth 2.1 too. Signing in gives access only to that agent.
- In an app's Access tab, a saved secret can be removed with Remove value. An OAuth connection has Sign out, which clears its tokens and keeps the client ID and secret.
- Error messages include a short hint about what to try.

## Changed
- Home no longer has the eight usage guides (features, agents, questions, settings, connections, skills and MCP, instructions, rewind). Ask Home what a setting does and it looks that up directly.
- Built-in skills have verb-and-noun names, such as check-domains and make-domain.

## Fixed
- A temporary error from an OAuth provider (for example a 503) no longer signs you out, for apps or MCP servers. Only a clear refusal of the refresh does.
