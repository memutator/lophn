# lophn 0.17.0

This release fixes Google sign-in in the browser tab, makes agent sessions look and behave the same everywhere, and lets you pick fonts from the ones installed on your computer.

## New
- Pin a floating panel so it stays above the other panels. The pin button is on the panel's bar.
- Double-click a floating panel's bar to dock it.
- Settings › Appearance lists the fonts installed on your computer. Search the list to pick one.
- Font, Code font, and Reading font each have their own weight.
- Reading font: choose whether documents and agent answers use the UI font, Serif, or a custom font.

## Changed
- A floating panel can move over the whole window, including the sidebars.
- A floating panel that is open and not pinned folds up when you click outside it. Clicks inside the browser tab count as outside.
- Agent sessions in the sidebar, the Agents tab, terminal tabs, and the new-session list share one look. The + button lines up with the status dots and × buttons, and hovering it lists lophn agents and Coding agents.
- Stopping a lophn session also removes its tab from the saved layout that shows it.
- Group tabs that are not selected no longer show ×. Close them with a middle-click, from the tab menu, or with × after selecting the group.
- Inbox Finished entries for terminals show the tab name on the top line and the agent name below it.
- Workflow rows in the sidebar show only a status dot.
- The window's close button turns red on hover.
- Font settings pick from the installed fonts list instead of a typed name.

## Fixed
- Google sign-in in the browser tab no longer stops with "This browser or app may not be secure."
- Inbox Finished entries for terminals outside the current view showed the folder name instead of the tab name.
- Some lophn sessions were missing their rename and stop buttons.
- The + button sat 4 px lower than the session rows beside it.
- A font that was not installed fell back to the default with no sign. It is now marked Not installed, and the default font is used.
