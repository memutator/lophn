# lophn 0.5.0

Each project and app is now split into domains, and each domain keeps its own instructions, document kinds, skills and artifacts. Agent-written HTML pages open in an Artifacts tab, and coding agents can reach app tools over MCP.

## New
- Domains: a project or an app holds one or more domains, each a separate work area for its agents. Create, archive and restore them from the project's Domains tab or from the app's details.
- Artifacts: a folder with an `index.html` that an agent writes opens as a page in the project's Artifacts tab. Opening an `.html` file from your own folder works the same way. Annotations you send from an artifact go to the agent session that last wrote that folder.
- Document kinds: a domain can describe its documents in a `kinds.yaml` file. Documents that break it show up as problems, and the Project Manager is opened to look at them.
- Coding agents (Claude Code, Codex, OpenCode) can call an app's tools over MCP while a preview of that app is running, including tools that take no input.
- The Operator edit screen lets you choose which domains an Operator works in, and the skills for each.
- Public app tools are shared across domains. A release that removes a public tool another domain still uses is blocked.

## Changed
- App tools replace the app API. An app declares tools with a name, description, input and output schema, and an effect, and each tool belongs to one of the app's domains.
- An app's tools no longer take a project. The project picker in the app view is gone.
- Agents see only the tools of their own domains, plus other domains' public tools.
- The project sidebar has Explorer, Agent, Artifacts and Domains tabs. The Contexts tab is gone.
- Rewind checks prove a write tool's undo only from calls that succeeded. A tool that could not be proven is reported, not failed.

## Fixed
- Release checks failed for every app on the rewind and examples checks, with invalid-input errors. They run again.
- Starting an app preview from the command line always failed.
- Previews of real apps could never start; the supervisor refused them.
- A coding agent's MCP call to a tool with no input always failed.
