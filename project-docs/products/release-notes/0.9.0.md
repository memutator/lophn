# lophn 0.9.0

This release makes agent answers appear as they are written, with Markdown, visible reasoning, and readable tool steps. It adds status and notifications for coding agents running in lophn terminals, sign-in with Claude and Google Antigravity subscriptions, and one kind of agent in place of the Project Manager, App Engineer, and Operator roles.

## New
- Sign in with a Claude subscription or a Google Antigravity account to use them as model providers.
- Agent answers stream in as they are written, rendered as Markdown with highlighted code blocks.
- Agent reasoning appears as "Thinking", then "Thought for …", and expands to a summary.
- Tool steps show readable titles, such as "Read 2 files · Searched 1 time", and back-to-back reads and searches are grouped.
- Coding agents started in a lophn terminal show their icon, a status dot on the tab, and notices when they finish or ask for permission. Install and uninstall their hooks from Settings › Coding agents.
- Terminal tabs can be renamed by double-clicking the tab bar or from the tab menu. Otherwise a tab follows the session name or title its coding agent sets.
- The project sidebar groups lophn agents under Agents, open sessions under Current, and finished sessions under Recent. Recent also includes saved terminal coding agent sessions; choosing one opens a terminal in that folder and resumes the session where the tool supports it.
- Agent notices are a toast when a lophn window has focus and an OS notification when it does not. Turns that finished while you were away collect in the notice panel, and an unseen finished turn shows a dot on its tab.
- The desktop window remembers its size, position, and maximized state.

## Changed
- lophn recognizes coding agents from 25 tools in its terminals. Gemini CLI and OpenClaw are no longer recognized.
- Coding agents that share a background server, such as Codex and OpenCode, run as their own process when started from a lophn terminal.
- Settings › Coding agents shows an icon for every tool, lists the tools found on this computer first, and has a search box. The sign-in and skill columns are gone.
- The "Worked for" time no longer counts the time spent waiting for your approval.
- Project Manager, App Engineer, and Operator are gone. Agents are one list shared across Home, projects, and apps, and each agent chat is tied to Home, a project, or an app.
- Agent names are unique across lophn. "lophn" is reserved for the built-in agent, which cannot be renamed or deleted.
- Long conversations no longer stop early at the context limit. lophn counts tokens closer to the model's own count, shortens older tool results during a turn, and compacts the conversation automatically between turns.
- Calls that hand work to another agent read "Handoff to", "Asked", or "Working with", and a failed call shows the reason.
- Terminal tabs keep their terminal when you switch tabs or panes. The "Some earlier output isn't shown" banner is gone.
- The first-open notice in terminals is gone. A restored terminal starts a new shell when you open its tab.
- The Claude icon is the orange starburst.
- lophn no longer ships Deno. It runs on the Node that comes with Electron, and apps are npm projects with no permission limits.

## Fixed
- A chat with a model through ChatGPT sign-in no longer ends with "model error".
- Claude Code's colors show in lophn terminals, including when the GPU cannot draw the terminal.
- Terminal programs use truecolor even when lophn was started from the desktop launcher or from an agent.
- A terminal resizes with its pane even when another pane has focus.
- Toasts inside a lophn window appear again, and the confirmation for closing a minimized terminal opens.
- The browser tab's back, forward, reload, address bar, and bookmark buttons work.
- Links in an agent's answer open in your browser instead of replacing the lophn window.
- Folders in Explorer no longer collapse by themselves when you open many of them.
- Scrollbars next to the resize handles scroll with the wheel and by dragging.
- Opening Settings › Coding agents no longer uses about ten seconds of CPU each time.
- A command the agent runs that times out, or that you stop by hand, now stops its whole process group. A command you stopped by hand is reported as a failure, not a success.
- lophn no longer stops responding on a busy machine.
- Creating an app without a network connection stops after two minutes instead of hanging.
- Adding a folder to a project no longer gets refused while an agent turn is running.
- A call that needs no answer is marked done when the receiving agent takes it, instead of staying "In progress".
- Scrolling up from the bottom of an agent chat no longer snaps back, and reopening a tab returns to where you were reading.

## Action needed
- Reinstall hooks in Settings › Coding agents for OpenCode, omp, and other plugin-based tools. Their plugin files were updated.
- Restart any coding agent that was already running when you installed its hooks. It reads hooks only when it starts.
- Project Manager, App Engineer, and Operator definitions and their saved sessions are not carried over. Start new agent chats.
- The tab layout saved by earlier versions is not read. lophn starts with a new layout.
