# lophn 0.15.0

This release lets apps share their skills with other agents, moves Project settings and App details into tabs, and simplifies Annotate.

## New
- An app can ship skills. An agent that is given the app also gets its public skills.
- An app's agent can ask you to share the app with other agents or with coding agents in your terminal. You approve or decline the request in the pending list.
- Coding agents in your terminal (Claude Code, Codex, pi, OpenCode) get the skills of the apps shared with them.
- The UI kit has a TimePicker for choosing a time from a list. For an end time, the list starts after the start time and shows each duration. Apps you already have get it from their next release.

## Changed
- Project settings and App details open as tabs. The gear next to a project or an app in the left sidebar opens the matching tab.
- Annotate is in the ⋯ menu of an app or artifact tab. While it is on, the top bar of the card shows the Annotate controls instead of a floating list and a toast.
- An agent's app access and blocked commands are kept in its definition file. Agents cannot change them; only you can.
- Global and project instructions are read from LOPHN.md, or from CLAUDE.md when there is no LOPHN.md. AGENTS.md is no longer read.
- Skills kept in the shared .agents skills folders are no longer read. Project skills are read from the project's own .lophn folder.

## Fixed
- The declaration check now says when the SDK installed for an app is older than the one its package.json asks for, and tells you to run npm install. It used to report an unknown field.
- Folded browser tabs keep their site icon instead of falling back to the globe icon.
- A skill whose description is written as a YAML block is no longer skipped without a message.
- Changing one place's skill list no longer removes skills from another place's agent.

## Action needed
- If your global or project instructions are in AGENTS.md, rename the file to LOPHN.md or CLAUDE.md.
- If you keep project skills in the shared .agents skills folders, move them into the project's .lophn folder.
