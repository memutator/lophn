# lophn 0.22.0

This release gives each workspace its own lophn agent with a memory, lets agents use browser tabs and app previews, and lets you delete archived apps for good.

## New
- Delete an archived app for good from the Archived section of Home's Workspaces panel. The confirmation lists what goes: the app's source and data, its conversations, releases, and records. Secret values and records of other apps and workspaces are kept.
- Every workspace (Home, each project, and each app) has its own lophn agent, with its own name, model, instructions, and MCP and skill settings.
- Agents and workspaces keep a memory file that is loaded at the start of each session. You can edit it in the Agents tab (up to 8 KiB each).
- Agents can open browser tabs and app previews, read pages, click, type, and take screenshots. You can take over a tab the agent is using at any time.
- App previews: a Preview button in the app's toolbar, with phone emulation. Register your devices in Settings > Browser.
- Agent teams: an agent can start helper sessions and end them. A helper's questions and approval requests go to its parent agent first, and reach you only when the parent cannot decide.
- Shell extensions can give agents their own tools. Assign them in the agent editor under "Shell extensions".
- App tray popups fit their content, and each app sets the size of its popup.
- Settings: reorder the tray items with up and down buttons.
- Keyboard shortcuts: more commands can be changed, including the command palette, Home, bookmarks, and terminal copy and paste. Extensions and apps can add their own shortcuts.
- Chat view (Claude Code, Codex, OpenCode, omp): a running `!` shell command can be stopped with a Stop button, and its command block has a button that puts the command in shell mode.
- Scroll the chat with PageUp, PageDown, Ctrl+Home, and Ctrl+End.

## Changed
- Closing lophn with Quit no longer stops background jobs. The background part keeps running for up to 10 minutes with nothing to do, then stops by itself. Choose "Stop lophn" in the tray menu to stop everything.
- Starting at login now starts only the background part, without opening the app window.
- The Agents tab shows only the global agents and the ones for the current workspace, each marked with its scope (All of lophn, a project name, or an app name).
- The agent keeps its earlier tool calls and their results in the next turn, so it no longer forgets what it looked at before.
- Chat view usage warnings read like "You've used 82% of your weekly limit. It resets Fri at 10:00." and appear once for each level.
- Long conversations in the chat view render faster and stream more smoothly.

## Fixed
- Deleting a session with hundreds of messages failed with "too many rows changed".
- In the terminal, after a reload or after returning to a project, mouse drag, click, and scroll stopped working in Claude Code and OpenCode. Emoji widths and copying text from inside those tools are fixed too.
- "Open as chat" for a newly started CLI was blocked until the first message was sent.
- Claude chat view: token and cost totals restarted from zero when the view was reopened.
- Claude chat view: slash-command output and compaction summaries showed as your own messages when the view was reopened.
- Claude chat view: a message sent while the agent was busy showed briefly in the conversation before moving to the queue.
- Claude chat view: a background subagent disappeared from the Running list too early.
- Chat view: "Open" on an edit card failed for relative paths.
- Chat view: the tab name showed the terminal path while you were in another workspace.
- Agents from another workspace appeared in the list but failed with "not found" when opened.
- A helper's question that the parent answered showed as cancelled.
- Agents' `lophn tab open`, `lophn browser`, and `lophn ext call` were always refused as forbidden.
- Published versions of your own packages are kept and restored at startup if their local copy goes missing. Version lists sort by number, so 0.10.0 comes after 0.9.0.

## Action needed
- Each workspace now has its own lophn. Your old global lophn settings were copied into every workspace on first start. Review each workspace's lophn in the Agents tab and adjust it there.
- Apps built on earlier SDK versions keep working. To use the new tray size, app shortcuts, or agent memory, update the app's SDK. The app's agent will show the update.
