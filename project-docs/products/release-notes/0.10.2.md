# lophn 0.10.2

Your existing data carries over to this version. Explorer can add and remove project folders, ChatGPT subscriptions sign in through the Codex service, and Claude subscriptions keep the prompt cache for an hour.

## New
- Explorer lists a project's folders. Add folder at the bottom picks one from your computer. The x at the end of a row removes that folder from the project. Its files stay on disk.
- Right-click a folder in Explorer and choose Open in Terminal to open a terminal in that folder.
- Apps can have folders besides their source, and the app's agent can read and change files in them. Add them under Folders in App details. Remove takes a folder out of the app and leaves its files on disk.
- The View button on a terminal notification opens that terminal tab, even when it is in another project.

## Changed
- Terminals open in the folder you chose in Explorer. lophn no longer asks which folder to use when a project has several.
- Subfolders under a project folder were removed. Each folder keeps its own description.
- ChatGPT subscription sign-in uses the Codex sign-in and the Codex service, so prompts can reuse their cache more. The button now reads Sign in with ChatGPT.
- Claude subscriptions keep the prompt cache for one hour instead of five minutes. API keys are unchanged.
- Gemini models through Antigravity keep their tool-call signatures within a turn.
- New apps write their screen text directly in their code. Apps you already made keep their current SDK version.

## Fixed
- For agents that report a stop through hooks (for example opencode, pi, omp, Cursor, Codex and Kimi), pressing Esc or Ctrl-C no longer makes a running turn look finished.
