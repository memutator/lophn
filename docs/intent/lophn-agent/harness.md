# lophn-agent/harness

## 왜
좋은 판단도 연결이 끊기거나 내 말을 놓치면 믿고 맡길 수 없다. 내가 고른 model로 일을 끝까지 돌리되, 기다림·중단·실패를 성공처럼 보이지 않게 해야 한다.

## 무엇을 약속하나

- **[I1]** 내가 고른 provider와 model(API key, 구독, 로컬)만 쓰고, 몰래 바꾸지 않는다.
- **[I2]** run이 어디까지 왔는지 보이고, 끊겨도 같은 일을 두 번 하지 않는다.
- **[I3]** model에는 필요한 자료만 적게 넣되, 내 최신 요청과 근거는 빠뜨리지 않는다.
- **[I4]** tool은 맡은 책임 범위 안에서만 쓴다.
- **[I5]** model 호출마다 무엇에 얼마나 썼는지 알 수 있다.
- **[I6]** credential 여러 개를 내가 정한 순서로 쓰고, 같은 provider 안에서만 넘어간다.
- **[I7]** 자료 속 지시(prompt injection)와 secret이 model의 행동으로 이어지지 않는다.
- **[I8]** 같은 tool이 계속 실패하면 멈춘다.
- **[I9]** 허락된 앱의 command는 따로 연결하지 않아도 tool로 쓴다.
- **[I10]** 매 turn 지금 시각과 내가 보고 있는 탭·앱 화면을 짧게 알고 시작한다.

## 하지 않는 것
- 코딩·웹 탐색·임의 파일 접근을 위한 도구를 주지 않는다.
- 불완전한 응답으로 행동하거나, 거절·결과 불명을 재시도로 우회하지 않는다.
- 비용의 모름을 0으로 채우거나 금액 상한으로 일을 막지 않는다.

## 잘되고 있다는 신호
- 재시작과 내 수정·멈춤 뒤에도 입력이나 효과가 중복되지 않는다.
- 같은 일을 더 적은 token으로 하고, 기다림과 비용의 이유를 확인할 수 있다.
