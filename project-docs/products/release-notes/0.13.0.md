# lophn 0.13.0

This release fixes app activations that failed after you had approved them, and makes buttons and colors more consistent.

## New
- In the notification panel, a Finished line can be dismissed with its Dismiss button, without opening its tab. The unread count goes down too. Permission and question requests stay until you answer them.
- When an app activation finishes after you approve it, the agent that made the app release is told the result. If it failed, the message gives the reason and says whether the previous release is running again.

## Changed
- With the default Ink accent, focus outlines and selections are no longer blue. Primary buttons and selected or switched-on items are dark, so one color marks the main action.
- Buttons that cannot be undone (confirm delete, Rewind, disconnect, clear a value, Stop in a workflow) are filled red with white text. Deny and Skip are now ordinary buttons.
- Text buttons have icons, and the same action uses the same icon everywhere. Cancel and Close stay text-only. Button groups sit at the right edge, with Close first and the main button last.
- Consent prompts, the waiting panel, the consent card in chat, and the app restart alert show the app's name instead of its short id.

## Fixed
- An app that asked to read or write a folder holding its own source was refused after you had already agreed. That refusal is gone; your consent prompt is now the only check.
- A rejected activation now says why, instead of only "the new release was not adopted".
