- 목표: 앱 SDK 너머 플랫폼 전체(durable workflow `flow_sdk`, 플랫폼 역량 메모, 작업 공간 정본 기반 영향 분석, 삭제·계약 변경 1단 결정적 정리 + 2단 `lophn` 인계, 통합 `follow_up_items`와 `/update`)를 한 체계로 구현한다.
- 재료:
  - `project-docs/products/roadmap/platform-update.md`
  - `project-docs/products/roadmap/cascade.md`
  - `project-docs/issues/workflow-rename-merges-desk-into-main.yaml`

- 범위 밖:
  - 기동 시 사람 개입 없이 program이 agent session을 여는 동작 (`event.md` 불변식 3)
  - `@lophn/flow` 멀티 버전 실행기
  - 기능 변화 없이 판만 맞추기 위한 앱·workflow 자동 수정
  - 사람이 쓴 `LOPHN.md` 자동 직접 수정
  - 다른 컴퓨터 구독자(`subscriptions[].machine`, `remote_apps`) 정적 추적 및 실시간 file watch cascade
- 단위:
  - `tooling`: `records.ts` `platform_note` 검사 및 `check-sdk-notes.ts` `platform-notes.json` 검증
  - `jobs`: 보관된 앱·project의 `job` 동적 건너뛰기와 agent·workflow 삭제/이름 변경 `job` 정리
  - `cascade-core`: `agent.delete` 결정적 정리, `artifacts.delete`, `flow_sdk` 도장·차단, `workflow.rename`·`workflow.delete`
  - `workspace-reader`: 작업 공간 정본 reader(`declared`/`mentioned` 영향 분석), `follow_up_items` CRUD, `release.prepare` 계약 변경 diff
  - `update-engine`: 통합 `update.status`·`update.decide`, `workspace_update_needed` 감지, `fresh: true` 시드, `sdk-decide_test.ts`
  - `cascade-handoff`: `release.activate` 사후 인계(`A21` 전환), 삭제 인계 session 라우팅, CLI 명령
  - `prompts-skills`: 내장 prompt·skill `description` 정렬, `/update` + 기준선 메모 3편, `@lophn/agent` `1.18.0` + SDK 메모
  - `shell-ui`: 삭제 확인 창(`[Delete & clean up now]` / `[Delete only]`), workflow 이름 변경·삭제 및 desk 동기화, `workspace_update_needed`·`target_unavailable` 표시

  - Step 0 (lead): 공유 protocol 계약(`follow_up`, `impact`, `update`, `artifacts.delete`, `workflow.rename|delete`), single schema step `workspace.lifecycle.tables`, 초기 flow 등록
  - Wave 1: `tooling-checks`, `jobs-archive-and-erase`, `cascade-deterministic-core`, `workspace-reader-and-followups` (4병렬)
  - Wave 2: `update-engine-and-notices`, `cascade-handoff-and-cli`, `prompts-skills-and-sdk-note`, `shell-cascade-and-desk-ui` (4병렬)
  - Wave 3 (lead): 호환 별칭 제거, `AGENT.md`·architecture·`flows`·`issues`·`change-log` 정리, 로드맵·계획 폴더 제거, `land.sh`
