# lophn-agent/harness

## 왜
lophn agent를 믿고 맡기려면 내가 고른 model로 돌고, 끊겨도 잃지 않고, 비용을 알 수 있어야 한다.

## 무엇을 약속하나

- **[I1]** 내가 고른 model과 provider로 돈다.
- **[I2]** 끊기거나 멈춰도 일을 잃거나 두 번 하지 않는다.
- **[I3]** 같은 일을 더 적은 비용으로 하고, 무엇에 얼마 썼는지 보인다.
- **[I4]** lophn agent 세션은 이어서 하거나 새로 시작할 수 있다.

## 하지 않는 것
- 불완전한 응답으로 행동하거나, 거절·결과 불명을 재시도로 우회하지 않는다.
- 비용의 모름을 0으로 채우거나 금액 상한으로 일을 막지 않는다.

## 잘되고 있다는 신호
- 재시작과 내 수정·멈춤 뒤에도 입력이나 효과가 중복되지 않는다.
- 같은 일을 더 적은 token으로 하고, 기다림과 비용의 이유를 확인할 수 있다.
