# lophn 0.14.0

Home, projects, apps, and Settings now share one window layout with tabs, split panes, and desks. Apps and projects can have their own icons, and each project has a settings tab.

## New
- One layout everywhere: Home, each project, each app, and Settings open in the same window, with a sidebar and tabs.
- Split panes: put two to four tabs side by side in one group. Drag a tab to the edge of a pane to split it, or onto the middle to swap it.
- Desks: create a desk, rename it, or close it. Closing a desk closes its tabs after you confirm, and unsaved files ask before they close.
- Project settings: each project window has a Project settings tab for the project's icon, name, purpose, and folder.
- Custom icons: upload an SVG, PNG, or WebP icon of up to 64 KiB for an app or a project. Your upload is shown instead of the icon the app declares.
- Jobs wait for your approval: a job an agent creates does not run until you approve it. Rejecting it deletes it.

## Changed
- Home opens in a new window instead of the launcher. The activity bar is gone. Open app panels from the + menu or from the App menu in the quick launch.
- Jobs moved out of Settings. Open them from Jobs or Inbox in the sidebar, from a tab, or from the right panel.
- Agent turns no longer stop after 30 minutes of work. A turn still stops if it makes no progress for 5 minutes.
- An app panel shows its status bar only when the app has stopped or crashed.

## Fixed
- The context usage in `/status` counts the last model call and everything added since. After Compact or a rewind it stays unknown until the next model call.
- The input token counts in the footer and the panel include cache writes, so they no longer look low on providers that bill cache writes separately.
- Jobs that call an app no longer fail silently because the agent that created them is not assigned to that app.
- Large results from an app's screen no longer fail. Screens receive results of up to 8 MiB.

## Action needed
- Jobs created before this version wait for approval. Approve each one once in Scheduled jobs before it runs again.
- Apps released before this version do not open. Release each app again.
- Window layouts from earlier versions are not carried over. Reopen the tabs and panels you use.
