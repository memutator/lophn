# lophn-agent

## 왜

lophn, 앱, agent를 쓰고 관리하는 일은 복잡하다. lophn agent가 그 복잡도를 추상화해서, 나는 원하는 것과 결정만 다룬다.

## 무엇을 약속하나

- **[I1]** lophn·앱·agent를 쓰고 관리하는 복잡한 일은 lophn agent가 맡고, 나는 원하는 것과 결정만 다룬다.
- **[I2]** 앱은 원하는 것만 말하면 만들고 고치고 챙기는 일이 coding agent까지 이어진다.
- **[I3]** lophn의 기능과 설정은 물어보면 지금 보는 화면에서 설명하고, 고르면 대신 바꿔 준다.
- **[I4]** 앱마다 담당 agent가 붙고, 프로젝트나 앱마다 반복해서 맡길 일은 agent를 필요한 만큼 구성한다.
- **[I5]** agent 구성(context, capability, MCP, skill, provider, model)은 preset으로 저장해 다시 쓴다.
- **[I6]** 판단과 제안은 agent가 하고, 결정과 허락은 내가 한다.
- **[I7]** 맡긴 일은 무엇을 왜 했는지 보이고, 마음에 안 들면 되돌린다.
- **[I8]** 내가 쓴 지침을 agent가 늘 읽고 따른다.

## 하지 않는 것

- lophn agent는 coding agent가 아니다. 코드를 짜지 않는다.
- 채팅 중심 비서를 만들지 않는다.
- agent의 완료 주장만으로 고쳤다고 인정하지 않는다.

## 잘되고 있다는 신호

- lophn과 앱과 agent의 설정을 몰라도 원하는 일이 된다.
- 같은 말을 다시 하지 않고, 맡긴 일의 근거·결과·멈춘 이유를 찾아 마음에 안 들면 되돌린다.
