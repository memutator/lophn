# lophn 0.2.0

This release moves project and app management into the launcher, makes the editor, Explorer and keyboard shortcuts work like VS Code, adds appearance settings and ChatGPT or SuperGrok sign-in, and fixes a number of agent and app problems.

## New
- Projects and apps are managed only from the launcher. Use a card's ⋯ menu to archive it, and restore it from the Archived section at the bottom. A project whose folder moved shows Choose new location.
- Settings opens from the button at the top right of the launcher and from the top bar of the workspace.
- Editor tabs work like VS Code: preview tabs, close with a middle click or Ctrl/Cmd+W, a right-click menu on tabs, drag tabs to reorder them or move them to the other pane, Ctrl+Tab to cycle through the tabs in a pane, and Ctrl+Shift+T to reopen a closed tab.
- Keyboard shortcuts for tabs, panes, the sidebar, Explorer, search, the terminal and quick open. Ctrl is used on Linux and Windows and Cmd on macOS. Ctrl+B toggles the sidebar, Ctrl+P opens quick open, and Ctrl+backtick focuses the terminal.
- Explorer has New File, New Folder, Refresh and Collapse All buttons, inline rename, drag to move, F2 and Delete keys, and Reveal in Explorer from an open tab.
- Deleting in Explorer moves files and folders to the system Trash instead of deleting them permanently.
- Appearance settings: accent color, background, font, code font, text size and density. The choice applies to lophn windows and to app views.
- ChatGPT and SuperGrok subscription accounts can be signed in as model providers: Continue with ChatGPT and Sign in with SuperGrok.
- Grants lists the tools of each connected MCP server, so you can set permission per tool. Servers that are off, need sign-in or cannot be read are not listed.
- The model list is downloaded from models.dev once a day, so new models appear without an app update.

## Changed
- The notifications button is a bell icon, and its panel is titled Notifications. It closes on an outside click or Esc.
- The right side of an app's workspace is one panel with tabs: App details, Agent, and the coding terminal.
- The terminal background matches the tab background, and terminal colors follow the theme.
- A model request that gets no response for 120 seconds is cut and retried. Output that keeps being cut off stops after three tries. Anthropic rate-limit errors retry within seconds instead of blocking the provider for an hour.
- Only the two newest images are sent to the model; older screenshots are left out.
- Annotations no longer carry a source file position. They show the component path, such as List > Card > Button, and the App Engineer can look at the annotated screenshot.
- Coding agent integration is installed once in your user settings instead of into each app folder. lophn asks you once before it does this.

## Fixed
- Connecting a cloud provider with an API key did nothing. It now creates the provider.
- The session list and pending permission requests did not load.
- After the agent runtime restarted, sessions stopped accepting new messages because the old turn was left running. That turn now ends as interrupted, and messages sent just before the restart are delivered again.
- Stopping a turn did not stop the model request. Archiving or deleting a session stops it now.
- Rewinding file changes failed with an internal error.
- Agents could not read or write project folders outside lophn's data folder. A draft folder opened by the Project Manager can be written in the same turn.
- Writes into draft and project folders could not be rewound.
- Some agent actions were refused as forbidden: ticket create, update, verify and cancel and app linking for the App Engineer; context drafts and operator changes for the Project Manager; call, reply, cancel and visual show for every role.
- Agent calls to app APIs returned unavailable.
- Image results reached the model as plain text, and turns with several screenshots stopped with a size error.
- Context chips in the composer did not reach the agent. They now do, and they stay in the message.
- Error reports from apps were rejected. They are accepted now and open a problem. An app that crashed before sending its report did not open a problem; lophn now waits up to 2 seconds for the report.
- One crash that repeats for the same reason is one problem. Before, a crash loop could open up to seven App Engineer sessions.
- Crashes of the app supervisor and the shell were not written to the diagnostic log.
- Preparing a release of an app that uses the SDK stopped with "sdk not installed" on a new data folder.
- The release bundle of the template app exceeded the file limit.
- Error stacks in apps with several screens did not point back to the source.
- Apps sometimes failed to start when more than one lophn instance ran for the same user.
- Commands from the coding agent CLI that write to apps were refused as unauthorized.
- Turning off an agent in Grants did not stop calls to it. Off now means off.
- Menus and model pickers opened at the window edge and could be cut off. The command palette and dialogs opened dark in light mode.
- Explorer file and folder icons were blank inside app views.
