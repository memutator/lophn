# lophn 0.10.3

Installed builds can run apps again, panes can be split up and down, and the place switcher is easier to scan.

## New
- Split a pane up or down as well as left or right. Use Split Right or Split Down in a tab's menu, or press `Ctrl+\` or `Ctrl+Shift+\`. Drag a border to resize. You can have up to six panes.
- The place switcher lists Projects and Apps in two groups, most recently opened first. Each project and app has a colored mark with its first letter: a rounded square for projects, a circle for apps. Launcher cards show the same mark.
- Each app remembers its side panel, its selected tabs, and the agent and session you were using.

## Changed
- The place switcher shows the current place name in the top bar. Its menu has no Recent group.
- A pane can be narrower (down to 320 px), so three panes fit in a 1500 px window.

## Fixed
- In an installed build, apps failed to start, and their release preparation ended with "exited before ready". Apps start now.
- The place menu no longer opens underneath an app's view.

## Action needed
- Install this version's package over the old one. The earlier installed build cannot start apps.
- If an app's release failed on an installed build, prepare that release again.
