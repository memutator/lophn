# lophn 0.10.0

The model picker shows only the models you use, terminals copy and paste with the usual keys, and instructions are edited where you read them.

## New
- Terminals on Linux and Windows copy with Ctrl+Shift+C and paste with Ctrl+Shift+V. On macOS, Cmd+C and Cmd+V still work.
- File paths in terminal output are links when the file exists. Ctrl-click (Cmd-click on macOS) opens the file at that line.
- Code blocks in chat for bash, sh and zsh have a Run in terminal button. A one-line command runs in a new terminal. A multi-line command is pasted there, and you press Enter to run it.
- Settings › General › Keyboard lists every workspace shortcut with a short description. Click a shortcut and press the new keys to change it. Reset to default and Reset all shortcuts bring back the defaults. Search finds a shortcut by name, description or key, and a toggle finds it by pressing its keys.

## Changed
- The model picker shows only the models you have turned on. Models from a new provider start off. Manage models turns them on and off. The model you are using stays visible even when it is off. If you have turned on no models for a provider, all of its models are listed.
- The first model you choose becomes your default when no default exists yet.
- Project instructions (LOPHN.md) are edited in place: click Edit in the instructions box, then Save or Cancel. DOMAIN.md opens in the same markdown editor, right under its domain in App details.
- Home no longer reads project instructions through a tool. When an agent works in a project, that project's instructions are part of its prompt.
- Settings › Agents › lophn uses the full width of the Settings page.
- A new tab opened from a terminal link, a file link in chat, or a search result goes to the other pane when you have two panes, and next to its source when you have one.
- Sending a message without a model is blocked, and the input box says why.

## Fixed
- Saving the effort for a model that appears only in the live model list no longer fails with "That didn't work. Nothing changed."
- A turn that ran without any model now says a model is required, instead of "configuration unavailable".
- In the launcher and Settings, Ctrl+B, Ctrl+P and Alt+number reach the page instead of being taken by lophn.
