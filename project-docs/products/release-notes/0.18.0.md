# lophn 0.18.0

This release makes agents easier to shape: a lighter runtime that uses only the tools you pick, Claude Code, Codex, and OpenCode as lophn agents, optional extensions, and many more keyboard shortcuts. Places are now called workspaces. Your existing data moves to the new layout the first time you start this version.

## New
- An agent can use the "bare" runtime, which loads only the tools (and skills) you choose. Set it in the agent's editor under Runtime.
- Agents have a one-line description and the kinds of input and output they accept (text, image, file). Other agents see this on the agent card.
- Images and files in a message sent to another agent reach the model directly.
- Claude Code, Codex, and OpenCode can run as lophn agents once the Harness extension is on.
- `claude gui`, `codex gui`, `opencode gui`, and `omp gui` open the CLI as a chat view inside the terminal tab. A toggle at the top of the tab switches between the chat view and the CLI's own terminal screen.
- Extensions are optional feature bundles. Install, turn on, turn off, or remove them in Settings › System › Extensions.
- A private workspace does not call or get called by other workspaces. Set it in Settings › Agents.
- Apps can have an agent chat on their own screen and can send you notifications. Notifications appear in Inbox under "From apps".
- Keyboard shortcuts now cover new browser, new session, new terminal, split, desk switching, floating, and the sidebar. You can also set a shortcut that opens an app's panel. Settings › Keyboard shows shortcuts that clash and lets you replace one.
- The sidebar shows a new Agent tab as a "New session" row before its first message. Terminal rows from other workspaces can be renamed and closed.
- lophn can be packaged for macOS and Windows. It has not been run on those systems yet.

## Changed
- Places are now called workspaces (Home, projects, apps). The settings group that applies everywhere is named Global.
- Domains and kinds are gone. An app's commands are named after the app.
- When a long turn fills the context, lophn summarizes the earlier part in the middle of the turn and continues. It drops old tool output only if the summary fails.
- A coding agent's terminal tab stays running while its subagents work. The finished notification comes once, when everything is done.
- File edits and calls show as edit and call rows while they run. Failed, denied, and cancelled ones stay visible with a Failed, Denied, or Cancelled mark.
- Calls between workspaces are allowed by default. Settings › Agents can block them by workspace or by agent.

## Fixed
- Terminal tabs keep their history when you come back to a project or reload the window. A long TUI session no longer loses its earlier output.
- A coding agent's "Finished" line in Inbox no longer stays after its terminal closes in another workspace.
- A bad value in settings.json only affects that setting. Saving settings no longer overwrites a key you edited by hand.
- A failed turn no longer stops the agent runtime.
- Provider errors show the reason and the request id in the chat.
- A sign-in the provider refuses shows as a failed sign-in, not a timeout.
- The session list loads faster when you have many sessions.
- If an app's data restore is interrupted, the original data comes back on the next start.

## Action needed
- Release each app again before it starts. The apps released before this version do not load until you do. If two of an app's commands share a name, rename one when you release it.
- To use Claude Code, Codex, or OpenCode as agents, or to open them with `claude gui` and the like, turn on the extension in Settings › System › Extensions.
- If you installed the coding-agent hooks before, press Install hooks again in Settings. Subagent status appears only after that.
- To use the new agent chat or notifications in an app, the app needs the matching helpers from the app SDK.
