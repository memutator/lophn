# lophn 0.16.0

This release makes it quicker to open apps and agents, makes tabs and split panes easier to use, and fixes several bugs in the sidebar and Explorer.

## New
- Hover over Terminal, Browser, or App to see your favorite coding agents, bookmarks, and app screens. Click a row to open it. Clicking the button still opens a tab as before.
- Settings › Quick launch: choose the order and visibility of the quick launch buttons, pin app panels, and choose whether each app screen opens as a Tab or a Float.
- Project settings › Quick launch: turn off "Use the global quick launch" to give one project its own order, visibility, and pins.
- Settings › Coding agents: set a Command for each agent (leave it empty for the default) and mark favorites with a star. Claude Code, Codex, and OpenCode start as favorites.
- A pane can hold several tabs. Open a document or URL next to a terminal and it joins that pane. Switch between its tabs with the ‹ n/m › control in the pane header, and use Move out of pane in the ⋯ menu to take a tab back out.
- Drag a single tab inside a group in the tab row to move only that tab. Drop a tab between two tabs of a group to add it to the group.
- Left sidebar: the + at the end of each place row starts a new session in that place. Right-click the + on the current place to pick a lophn agent or a coding agent. Hover over an open session to show Rename and Stop. Stop ends the running turn and closes its tab.

## Changed
- Tabs are as wide as their names. Long names are shortened only in tabs that are not selected. Groups show all their names when the tab row has room; when it does not, unselected groups collapse to icons first.
- The New session row at the top of the left sidebar is gone. Use the + on a place row instead.
- Each tab has one spot for its close button, after its name. A status dot or unsaved dot shows there when the tab has one; the × appears on hover or focus.
- App command results that are too large are no longer cut down or replaced with a "too large to show" message. The full result is saved to a file, and the agent gets its start and the file path.

## Fixed
- Opening Domains, Artifacts, Workflows, or Scheduled jobs from the right sidebar while Files was open could blank the whole window. It no longer does.
- Copy Path and Copy Relative Path in Explorer, and copying from code blocks, Markdown, and tables, failed with a permission error. They work again.
- Deleting a file in Explorer on Linux took about 5 seconds. It is now quick.
- A tab's × could close the tab beside it and break a group apart. Each × now closes only its own tab.
