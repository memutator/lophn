# shell/desktop

Electron main과 창별 shell 화면의 분리, 창 구성·탐색·tray·OS 통합과 사람 token 보관을 맡는다; 각 화면에서 보여 줄 사실과 상태는 해당 concern을 가리키고 이 문서는 위치·순서·조작을 정한다.

## 요구

### 화면과 조작

**[R1]** 문서·앱 탐색을 기본 화면으로 두고 lophn-agent/conversation의 대화는 결과를 만들고 고치는 보조 패널로 열며 닫아도 문서·앱·변경 기록의 탐색을 유지한다.
- 이유: 산출물 탐색을 대화 사용 여부에 종속시키지 않는다.
- 확인: 대화를 한 번도 열지 않거나 닫아도 같은 산출물을 탐색해 연다.
- 의도: shell#I1

**[R2]** 대화는 오른쪽 400px 패널로 본문을 밀고 320px 정보 패널과 자리를 공유하여 임시로 접으며 본문 480px를 남길 수 없으면 overlay로 바꾸고 닫으면 이전 정보 패널 상태로 돌아간다.
- 이유: 좁은 창에서도 본문과 입력을 보존한다.
- 확인: 넓은 창은 본문 옆 패널이고 좁은 창은 overlay이며 native view 처리는 shell/app-frame을 따른다.
- 의도: shell#I5

**[R3]** lophn-agent/conversation의 결과 링크는 답 아래와 역할 상세의 만든 것에 두고 4개 이상이면 첫 3개·남은 개수·나머지 결과 보기를 배치한다.
- 이유: 긴 결과 목록이 답을 밀어내지 않게 한다.
- 확인: 결과 5개 중 처음 3개와 나머지 2개를 모두 열 수 있다.
- 의도: shell#I1

- 이유: 역할을 바꿔도 익숙한 위치에서 일을 찾고 소유 concern이 새 요청을 금지한 담당에는 사용할 수 없는 입력을 보이지 않는다.
- 확인: 역할을 바꿔도 같은 위치에서 내용을 읽으며 회수된 담당은 과거 대화를 읽되 새 대화를 보낼 수 없고 멈춘 담당의 입력 가능 여부는 소유 concern의 현재 정책을 그대로 따른다.
- 의도: shell#I1

- 이유: 대기·중단과 새 요청을 혼동하지 않게 한다.

**[R31]** settings 화면은 왼쪽 세로 nav에 자리를 묶음 제목 아래 아이콘과 이름으로 놓고, 고른 자리 하나를 nav 오른쪽 자리의 가운데 column(form 폭)에 section 제목과 카드(왼쪽 이름·설명, 오른쪽 조작)로 그린다. 가로 탭 줄을 쓰지 않고 backup 자리는 두지 않는다.
- 이유: 자리가 늘어도 이름이 잘리거나 가로로 scroll하지 않고, 어디에 무엇이 있는지 한눈에 찾게 한다.
- 확인: 통로가 있는 자리만 묶음 아래 nav에 서고 고른 자리가 표시되며, 본문 column이 nav 오른쪽 자리의 가운데에 놓인다.
- 의도: shell#I1
