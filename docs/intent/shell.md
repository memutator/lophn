# shell

## 왜
코드를 읽지 않는 사람에게 lophn의 가치는 화면으로 전해진다. 복잡한 것은 숨기고, 문서와 앱을 앞에 둔다.

## 무엇을 약속하나

- **[I1]** 화면에는 지금 필요한 것만 보이고, 복잡한 것은 펼쳐야 보인다.
- **[I2]** 프로젝트 탭에서 문서 옆에 터미널과 앱 패널을 함께 띄워 둔다.
- **[I3]** 새 앱도 lophn과 같은 모양과 같은 말이라 배우지 않고 쓴다.
- **[I4]** 메뉴나 확인 창을 열어도 앱 화면이 사라지지 않는다.
- **[I5]** 무엇이 깨지거나 끊겨도 쓰던 내용을 잃지 않는다.

## 하지 않는 것
- 채팅을 기본 작업 화면으로 삼거나 코딩용 화면을 만들지 않는다.
- 접근성(screen reader, 대비 검증)은 지금 범위가 아니다.

## 잘되고 있다는 신호
- 새 앱에서도 쓰는 법을 다시 배우지 않는다.
- 앱 고장·저장 충돌·연결 단절 뒤에도 내 글이 남는다.
