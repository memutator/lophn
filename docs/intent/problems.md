# problems

## 왜
앱은 바깥이 바뀌면 조용히 깨진다. 깨진 것을 사람보다 먼저 알고, 고쳐졌는지 확인해야 유지 비용이 줄어든다.

## 무엇을 약속하나

- **[I1]** 앱이 깨지면 내가 알기 전에 lophn이 먼저 알고, 그때의 화면과 기록을 남긴다.
- **[I2]** 이상하면 한 번 눌러 알리고, 같은 걸 다시 설명하지 않는다.
- **[I3]** 고쳐졌다고 하면 테스트나 내 확인으로 확인된 것이고, 다시 깨지면 다시 열린다.

## 하지 않는 것
- agent나 앱의 "고쳤다"는 말만으로 문제를 닫지 않는다.

## 잘되고 있다는 신호
- 내가 알아채기 전에 이상과 당시 증거가 남는다.
- 다음 수리에서 지난 시도를 다시 설명하지 않아도 된다.
